Gupta Hospital Voice Prescription PWA

This version is installable as a Progressive Web App (PWA) when served over HTTPS.

For local testing on a computer:
1. Extract the ZIP.
2. In the folder run a local web server (for example: python -m http.server 8080).
3. Open http://localhost:8080 in Chrome.

For phone installation:
1. Host the entire folder on an HTTPS website.
2. Open that website in Chrome (Android) or Safari (iPhone).
3. Android: tap the in-app “Install App” button when available.
4. iPhone: tap Share > Add to Home Screen > Add.

Important: microphone dictation and PWA installation are designed for HTTPS (localhost is allowed for local development).
